Twitch Chat Overlay
===================

Прозрачное окно поверх всех приложений с чатом любого Twitch-канала.

УСТАНОВКА
---------
1. Установите Python 3.10+ (https://www.python.org/) — при установке
   обязательно отметьте "Add Python to PATH".
2. (Рекомендуется) Установите дополнительные модули:

       pip install keyboard pystray Pillow

   * keyboard       — глобальные горячие клавиши (Ctrl+Alt+H / Ctrl+Alt+Q),
                      работают из любого приложения. Без него хоткеи
                      срабатывают только когда окно в фокусе. На Windows
                      иногда требует запуска от имени администратора.
   * pystray + Pillow — иконка приложения в системном трее с меню
                        (показать/скрыть, поверх окон, прозрачность,
                        смена канала, выход). Без них трей просто
                        не появится — окно работает как раньше.

ЗАПУСК
------
Способ 1 — двойной клик по twitch_overlay.py
   Появится диалог, в котором нужно ввести имя канала (без #).

Способ 2 — из командной строки с указанием канала сразу:
   python twitch_overlay.py shroud

УПРАВЛЕНИЕ
----------
* Перетаскивание   — за тёмную полоску заголовка вверху.
* Изменение размера — за уголок ◢ в правом-нижнем углу или за
                      правый/нижний край окна.
* Кнопки в шапке (справа налево):
      ✕   — закрыть
      📌  — вкл/выкл "поверх всех окон"
      —   — свернуть (окно остаётся в трее и в панели задач)
      ⟳   — сменить канал
      ◐   — прозрачный фон (chroma key, только Windows): фон становится
            полностью прозрачным, остаются только текст и шапка.
            Через прозрачные части можно кликать сквозь окно.
* Слайдер прозрачности внизу — общая непрозрачность всего окна.

ИКОНКА В ПАНЕЛИ ЗАДАЧ WINDOWS
-----------------------------
На Windows окно появляется в панели задач со своей фиолетовой иконкой
(буква T). Можно щёлкать по ней для сворачивания/восстановления, как
у обычного приложения.

Горячие клавиши (когда окно в фокусе):
      Esc                          — скрыть окно
      + / −                        — общая прозрачность
      Ctrl + + / Ctrl + −          — увеличить / уменьшить шрифт чата
      Ctrl + 0                     — сбросить шрифт к 10 pt
      Ctrl + колесо мыши           — изменить шрифт чата
      Ctrl+Q                       — выход

Глобальные горячие клавиши (если установлен `keyboard`):
      Ctrl+Alt+H   — скрыть/показать окно
      Ctrl+Alt+Q   — выход

СИСТЕМНЫЙ ТРЕЙ
--------------
Если установлены pystray и Pillow, в трее появится фиолетовая иконка с
буквой T. По двойному клику — показать/скрыть окно. По правому клику:
   * Показать / Скрыть
   * Поверх всех окон (галочка)
   * Сменить канал…
   * Прозрачность ▸ (быстрые пресеты 30/50/75/90/100%)
   * Выход

ФАЙЛЫ
-----
* overlay_config.json — сохранённые позиция/размер/прозрачность.
* chat_history.txt    — лог всех принятых сообщений (дописывается).
* icon.png / icon.ico — иконка приложения и трея.

СБОРКА В ОДИН .EXE
------------------
Чтобы получить автономный twitch_overlay.exe с фиолетовой иконкой
(видна в Explorer, на Рабочем столе, в панели задач, в Alt+Tab и в трее):

   1. Положите рядом со скриптом файлы icon.ico и icon.png (уже есть).
   2. Запустите build.bat двойным кликом.
      Скрипт сам поставит pyinstaller, pystray, Pillow и keyboard,
      и соберёт всё через twitch_overlay.spec.
   3. Готовый файл появится в  dist\twitch_overlay.exe — это
      один автономный .exe, его можно перенести куда угодно.

Если хочется собрать вручную:
   pyinstaller twitch_overlay.spec

ИКОНКА НЕ ПОДТЯНУЛАСЬ?
----------------------
* Если иконка .exe в Explorer старая — Windows кэширует превьюшки.
  Запустите в PowerShell:
     ie4uinit.exe -show
  или просто переместите .exe в другую папку и обратно.
* Если в taskbar всё равно стандартная Tk-иконка — убедитесь, что
  собирали через twitch_overlay.spec (там прописан icon='icon.ico'
  и икона добавлена в datas), а не одной командой без spec.

ПРИМЕЧАНИЯ
----------
* Подключение анонимное (justinfan...), OAuth-токен не требуется,
  читаются только сообщения — отправлять в чат нельзя.
* Если связь с Twitch потеряется, программа автоматически попытается
  переподключиться (с экспоненциальной задержкой до 30 секунд).
* Системные сообщения подключения/переподключения в чат больше
  не выводятся — состояние видно только по индикатору в статус-баре.
* Шапка, статус-бар и слайдер прозрачности скрываются автоматически,
  когда курсор уходит с окна — остаётся только сам чат. Наведитесь
  обратно — панели появятся снова.
