## Возможности

- **Анонимное подключение** к Twitch IRC — без OAuth-токена и регистрации.
- **Поверх всех окон** (always-on-top) — удобно во время игры/работы.
- **Интеграция с OBS Studio по ссылке** — страница для Browser Source и отдельная для Dock.
- **Редактор оформления Browser Source** — плашки под сообщениями и никами
  (цвет, градиент, стекло с размытием, обводка, тень, акцент цветом ника),
  свои картинки-подложки, которые тянутся под длину текста (9-slice),
  шрифты с кириллицей, анимации появления, автоскрытие, готовые пресеты.
- **Регулируемая прозрачность** — слайдер 20–100% или хоткей `+`/`−`.
- **Прозрачный фон** (chroma key, Windows) — фон полностью невидим, через
  него можно кликать насквозь, остаётся только текст чата.
- **Перетаскивание** мышью + ресайз за края и угол.
- **Регулируемый размер шрифта** — кнопки `A+ / A−`, `Ctrl + колесо мыши`,
  `Ctrl + +/−`, `Ctrl + 0`.
- **Авто-скрытие шапки/футера** — когда курсор уходит с окна, остаётся
  только сам чат.
- **Сохранение истории** в `chat_history.txt` (можно отключить).
- **Системный трей** с меню (показать/скрыть, поверх окон, прозрачность,
  смена канала, выход).
- **Иконка в панели задач Windows** — настоящая, не дефолтная Tk.
- **Автоматическое переподключение** при обрыве связи.

## Быстрый старт

### Запуск из исходников

```bash
git clone https://github.com/Max4Paw/twitch-chat-overlay.git
cd twitch-chat-overlay
pip install -r requirements.txt
python twitch_overlay.py
```

При запуске появится диалог — введите имя канала (без `#`).
Можно сразу указать канал в командной строке:

```bash
python twitch_overlay.py shroud
```

### Сборка `.exe` для Windows

```bat
build.bat
```

Скрипт сам поставит зависимости (PyInstaller, pystray, Pillow, keyboard),
соберёт автономный `dist\twitch_overlay.exe` с фиолетовой T-иконкой и
почистит кэш иконок Windows. Готовый файл можно переносить куда угодно —
он не зависит от установленного Python.

## Управление

### Кнопки в шапке (справа налево)

| Кнопка | Действие |
| --- | --- |
| `✕` | Закрыть |
| `📌` | Включить/выключить «поверх окон» |
| `⟳` | Сменить канал |
| `◐` | Прозрачный фон (chroma key, Windows) |
| `A+` / `A−` | Размер шрифта чата |
| `—` | Свернуть в трей |

### Горячие клавиши (когда окно в фокусе)

| Клавиши | Действие |
| --- | --- |
| `Esc` | Скрыть окно |
| `+` / `−` | Общая прозрачность |
| `Ctrl + +` / `Ctrl + −` | Размер шрифта |
| `Ctrl + 0` | Сбросить шрифт |
| `Ctrl + колесо мыши` | Размер шрифта |
| `Ctrl + Q` | Выход |

### Глобальные (если установлен `keyboard`)

| Клавиши | Действие |
| --- | --- |
| `Ctrl + Alt + H` | Скрыть/показать окно |
| `Ctrl + Alt + Q` | Выход |

## Зависимости

Минимально нужен Python 3.10+ со встроенным `tkinter`.
Опциональные пакеты:

| Пакет | Зачем нужен |
| --- | --- |
| `pystray` + `Pillow` | Иконка в системном трее с контекстным меню |
| `keyboard` | Глобальные горячие клавиши (работают из любого окна) |
| `pyinstaller` | Только для сборки `.exe` |

Установить всё разом:

```bash
pip install -r requirements.txt
```

## OBS Studio (Dock и Browser Source)

Программа поднимает локальную веб-страницу (по умолчанию на `127.0.0.1:17655`) и отдаёт две ссылки:

- **OBS Dock (Custom Browser Dock)**: `http://127.0.0.1:17655/obs/dock`
- **OBS Browser Source (Источник “Браузер”)**: `http://127.0.0.1:17655/obs/browser`

### Как добавить Dock (панель) в OBS

Открой в OBS: `View → Docks → Custom Browser Docks…`, вставь ссылку дока и задай имя (например “Twitch Chat”).

### Как добавить Browser Source (как источник)

Добавь источник `Browser` и вставь ссылку браузер-оверлея.

- Для прозрачного фона используй обычные настройки OBS (страница сама рендерится на прозрачном фоне).
- Если в OBS включена опция “Local file” — её нужно **выключить** (мы используем URL).

### Настройки

Порт и включение веб-страницы сохраняются в `overlay_config.json`:

- `obs_web_enabled` (по умолчанию `true`)
- `obs_web_port` (по умолчанию `17655`)

## Как это работает

Подключение идёт по стандартному Twitch IRC-протоколу через сокет на
`irc.chat.twitch.tv:6667` под анонимным ником `justinfan*****`. Это
официально поддерживаемый Twitch'ем способ читать чат без авторизации,
поэтому не требуется ни регистрация, ни OAuth-токен — но и отправлять
сообщения нельзя, только читать.

Окно использует `tk.overrideredirect(True)` (без рамки), а через
Win32 API (`SetWindowLongPtrW` + `WS_EX_APPWINDOW`, `WM_SETICON`,
`SetCurrentProcessExplicitAppUserModelID`) появляется в taskbar
с собственной иконкой. Прозрачный фон реализован через
`-transparentcolor` (доступно только в Windows-версии Tk).

## Оформление чата в OBS (Browser Source)

1. **Настройки → OBS → «Открыть редактор оформления»** (или откройте
   `http://127.0.0.1:17655/obs/editor` в браузере, пока программа запущена).
2. Выберите готовый стиль и подкрутите его: плашка сообщения, плашка ника,
   текст, расположение, анимация.
3. **«Сохранить и применить»** (или `Ctrl+S`) — Browser Source в OBS
   обновится сам, перезагружать источник не нужно.

**Своя картинка-плашка.** В «Плашка сообщения» (или «Плашка ника») выберите
тип «Картинка» и загрузите PNG/WEBP (можно перетащить файл). В режиме
**9-slice** картинка делится розовыми линиями на 9 частей: углы остаются
как есть, а края и середина растягиваются под длину сообщения — рамки,
облачка и ленты не искажаются. Режимы «Растянуть», «Заполнить» и «Плитка» —
для фоновых текстур.

Стиль хранится в `obs_style.json`, загруженные картинки — в папке
`obs_assets/` рядом с программой. Кнопки «Экспорт / Импорт» позволяют
сохранить стиль в файл и поделиться им. Добавьте `?demo=1` к ссылке
Browser Source, чтобы увидеть в OBS поток тестовых сообщений.

### Сообщение на экран

Добавьте в OBS ещё один Browser Source: `http://127.0.0.1:17655/obs/featured`.
Кликните сообщение в Dock-панели (или ПКМ по сообщению в окне программы →
«Показать на экране OBS») — оно крупно появится в этом источнике.
Масштаб, позиция и время показа настраиваются в редакторе → «Сообщение на экран».

### Пресеты и роли

В редакторе → «Мои пресеты» можно сохранить несколько оформлений и
переключать их одной кнопкой в программе: Настройки → OBS → «Пресеты».
Раздел «Стример, модераторы, VIP» задаёт им свой цвет фона, рамку и цвет ника.

### Звук

Настройки → «Звук»: сигнал при подсветке/упоминании, событиях канала или
каждом сообщении, 4 встроенных звука или свой WAV, громкость.

### Цель стрима и последние события (v0.1.4)

Ещё два Browser Source:
- `http://127.0.0.1:17655/obs/goal` — полоса цели (подписки или битсы), растёт сама.
  Название, цель и текущее значение — в редакторе → «Цель стрима».
- `http://127.0.0.1:17655/obs/recent` — последняя подписка, подарок, рейд, топ битсов.

### Прочее

- **Фильтры:** «Скрывать ботов» (Nightbot, StreamElements и др.) и «Скрывать команды» (`!…`).
- **Новые зрители:** первое сообщение зрителя на канале отмечается «👋» (окно и OBS).
- **Статистика:** клик по счётчику в строке статуса или Настройки → Ещё.
- **Перевод:** Настройки → Ещё → «Переводить иностранные сообщения» (Google Translate).
- **Обновления:** проверка последнего релиза на GitHub при запуске.

### DonationAlerts (v0.1.5)

Настройки → «Донаты»:
1. На donationalerts.com → Приложения создайте приложение, в «URL перенаправления»
   вставьте `http://127.0.0.1:17655/da/callback` (кнопка «Копировать» в программе).
2. Скопируйте ID приложения и Ключ API в программу → «Подключить» → «Разрешить» в браузере.

Донаты появляются в окне, в OBS-чате (свой цвет в редакторе → «События»), считаются
в «Цели стрима» (тип «Донаты ₽») и в «Последних событиях» (последний и топ донат).
