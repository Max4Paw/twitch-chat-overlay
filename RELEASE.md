## ✨ Что это

Лёгкий **прозрачный оверлей с чатом Twitch**, который висит поверх
любого окна — стрима, игры, монтажа. Анонимное подключение, без
OAuth-токена и регистрации. Современный тёмный интерфейс,
системный трей, иконка в панели задач Windows.

---

## 📦 Что внутри этой беты

- 💬 Анонимное чтение чата любого Twitch-канала.
- 🪟 Окно поверх всех приложений (always-on-top).
- 🎚️ Слайдер прозрачности 20–100% и режим **прозрачного фона**
  (chroma-key, click-through на пустые области).
- ✋ Перетаскивание мышью + ресайз за края и угол.
- 🔠 Регулируемый размер шрифта (`A+ / A−`, `Ctrl + колесо мыши`,
  `Ctrl + +/−`, `Ctrl + 0`).
- 👻 **Авто-скрытие шапки и футера** — когда курсор уходит с окна,
  на экране остаётся только чистый чат.
- 📌 Системный трей с меню (показать/скрыть, прозрачность,
  смена канала, выход).
- 🪟 Настоящая иконка в панели задач Windows — не дефолтная Tk.
- 💾 Сохранение позиции, размера, прозрачности и шрифта между запусками.
- 🔁 Автоматическое переподключение при обрыве связи.
- 📜 Лог всех принятых сообщений в `chat_history.txt`.

## 🚀 Как запустить

### Вариант А — готовый `.exe` (проще всего)

1. Скачай **`twitch_overlay.exe`** из секции **Assets** ниже ⬇️
2. Запусти двойным кликом — Python и зависимости не нужны.
3. Введи имя канала Twitch (например `shroud`) и жми **Подключиться**.

> При первом запуске Windows SmartScreen может ругнуться
> «Неизвестный издатель» — это нормально для unsigned-сборок.
> Жми **Подробнее → Выполнить в любом случае**.

### Вариант Б — из исходников

```bash
git clone https://github.com/Max4Paw/twitch-chat-overlay.git
cd twitch-chat-overlay
pip install -r requirements.txt
python twitch_overlay.py
```

## ⌨️ Управление

| Действие | Способ |
| --- | --- |
| Перетащить окно | За тёмную полоску заголовка |
| Изменить размер | За правый/нижний край или угол `◢` |
| Скрыть/показать панели | Просто увести/навести курсор |
| Прозрачность | Слайдер внизу или `+` / `−` |
| Размер шрифта | `A+ / A−`, `Ctrl + колесо`, `Ctrl + +/−` |
| Прозрачный фон | Кнопка `◐` в шапке |
| Сменить канал | Кнопка `⟳` в шапке |
| Скрыть в трей | `Esc` или кнопка `—` |
| Выход | `Ctrl + Q` или кнопка `✕` |

Глобальные хоткеи (если установлен `keyboard`):
`Ctrl + Alt + H` — скрыть/показать, `Ctrl + Alt + Q` — выход.

---

## 🐛 Известные проблемы

- Прозрачный фон (chroma-key) работает **только на Windows** — на
  других ОС кнопка `◐` сообщит, что режим недоступен.
- Глобальные хоткеи через библиотеку `keyboard` иногда требуют
  **запуска от имени администратора**.
- Кэш иконок Windows может показывать старую иконку для `.exe`
  после обновления — `build.bat` автоматически чистит кэш, но
  если вы скопировали `.exe` вручную, иногда нужна перезагрузка ПК.

## 🛠️ Системные требования

- **Windows 10 / 11** (есть и Linux/macOS, но без некоторых фич:
  иконка taskbar и chroma-фон — Win-only).
- Для `.exe` — ничего, всё уже внутри.
- Для запуска из исходников — Python **3.10+**.
